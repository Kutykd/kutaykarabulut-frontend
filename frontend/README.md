# Kampüs Etkinlikleri

Kutay Karabulut - 2321032056

Vite, React ve TypeScript ile yapılmış kampüs etkinlikleri sitesi. Sayfalar React Router ile, etkinlik listesi Context ile yönetiliyor.

## Çalıştırma

```
cd frontend
npm install
npm run dev
```

## Sayfalar

- `/` ana sayfa
- `/events` etkinlikler, arama ve kategori filtresi
- `/events/:id` etkinlik detayı
- `/admin` yönetim, silme
- `/admin/new` etkinlik ekleme
- `/admin/:id/edit` etkinlik güncelleme
- `/login` giriş
- `/register` kayıt
- `/forgot-password` şifremi unuttum
- `*` sayfa bulunamadı
